## Featured Projects

### 📺 [BDIX-IPTV — IPTV Playlists and XMLTV EPG](https://github.com/saeidrahmanbd/BDIX-IPTV)

<p align="center"><a href="https://github.com/saeidrahmanbd/BDIX-IPTV"><img src="https://raw.githubusercontent.com/saeidrahmanbd/BDIX-IPTV/main/assets/iptv-project-showcase.svg" alt="BDIX-IPTV project overview showing playlists, metadata, XMLTV EPG and logo maintenance" width="100%"></a></p>

A curated multi-country IPTV playlist project featuring Bangladesh, India, Pakistan and eligible international channels. The repository focuses on organized M3U/M3U8 playlists, channel logos, metadata quality, XMLTV EPG mapping, stream diagnostics and backup management.

- [Open the main M3U playlist](https://raw.githubusercontent.com/saeidrahmanbd/BDIX-IPTV/main/IPTV-Playlist.m3u)
- [Open the International M3U playlist](https://raw.githubusercontent.com/saeidrahmanbd/BDIX-IPTV/main/International-Playlist.m3u)
- [Visit the BDIX-IPTV project website](https://saeidrahmanbd.github.io/BDIX-IPTV/)

### 🛠️ [Playlist Studio 5.1 — Windows M3U/M3U8 Playlist Manager](https://github.com/saeidrahmanbd/Playlist-Studio)

<p align="center"><a href="https://github.com/saeidrahmanbd/Playlist-Studio"><img src="https://raw.githubusercontent.com/saeidrahmanbd/BDIX-IPTV/main/assets/Playlist-Studio-5.1.JPG" alt="Playlist Studio 5.1 Windows application with playlist editor, XMLTV EPG centre, stream scanner and player" width="100%"></a></p>

A portable Windows application for managing, editing, organizing, testing and playing M3U/M3U8 playlists. Features include an XMLTV EPG centre, stream scanner, built-in playback, channel metadata editing, duplicate detection, Xtream Codes and Stalker Portal / MAC support.

- [Download Playlist Studio 5.1](https://github.com/saeidrahmanbd/Playlist-Studio/releases/download/v5.1/Playlist-Studio-5.1.exe)
- [Read the product documentation](https://github.com/saeidrahmanbd/Playlist-Studio#documentation)
- [View v5.1 release notes and downloads](https://github.com/saeidrahmanbd/Playlist-Studio/releases/tag/v5.1)
- [Visit the Playlist Studio product page](https://saeidrahmanbd.github.io/BDIX-IPTV/playlist-studio.html)
